# 📌 Project Overview

The **Stock Market Analysis & Visualization** project focuses on analyzing historical stock market data using Python. The notebook performs data cleaning, descriptive statistics, exploratory data analysis (EDA), and visualizations to better understand stock price movements and trading behavior.

This project demonstrates how Python libraries can transform financial data into meaningful insights through statistical analysis and graphical visualizations.

---

# 🎯 Objectives

- Load and explore the stock market dataset.
- Identify missing values and duplicate records.
- Analyze Open, High, Low, and Close prices.
- Study trading volume patterns.
- Visualize stock market trends.
- Perform correlation analysis.
- Generate meaningful insights using EDA.

---

# 📂 Dataset Information

The dataset contains the following columns:

| Column Name | Description |
|-------------|-------------|
| Date | Trading Date |
| Open | Opening Stock Price |
| High | Highest Price of the Day |
| Low | Lowest Price of the Day |
| Close | Closing Stock Price |
| Volume | Number of Shares Traded |
| Dividends | Dividend Paid |
| Stock Splits | Stock Split Information |
