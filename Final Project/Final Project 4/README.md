# 📌 Project Overview

The **Air Quality Analysis & Visualization** project focuses on exploring environmental data using Python. The notebook performs data cleaning, descriptive statistics, exploratory data analysis (EDA), and visualizations to understand the behavior of different air pollutants and environmental factors.

This project demonstrates how Python libraries can be used to analyze real-world environmental datasets and generate meaningful insights through charts and statistical analysis.

---

# 🎯 Objectives

- Load and explore the Air Quality dataset.
- Identify missing values.
- Analyze different air quality parameters.
- Perform statistical analysis.
- Visualize pollutant trends.
- Understand relationships among environmental variables.
- Generate meaningful insights from the dataset.

---

# 📂 Dataset Information

The dataset contains the following columns:

| Column Name | Description |
|-------------|-------------|
| Date | Observation Date |
| Time | Observation Time |
| CO(GT) | Carbon Monoxide Concentration |
| PT08.S1(CO) | CO Sensor Response |
| NMHC(GT) | Non-Methane Hydrocarbons |
| C6H6(GT) | Benzene Concentration |
| PT08.S2(NMHC) | NMHC Sensor Response |
| NOx(GT) | Nitrogen Oxides |
| PT08.S3(NOx) | NOx Sensor Response |
| NO2(GT) | Nitrogen Dioxide |
| PT08.S4(NO2) | NO₂ Sensor Response |
| PT08.S5(O3) | Ozone Sensor Response |
| T | Temperature |
| RH | Relative Humidity |
| AH | Absolute Humidity |
