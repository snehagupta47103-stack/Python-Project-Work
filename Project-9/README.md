---

# 🎯 Project Objective

The objective of this project is to build a complete Sales Data Analysis System that helps users:

- Load sales data from CSV files
- Explore and understand datasets
- Handle missing values
- Perform mathematical and statistical analysis
- Search, sort and filter records
- Combine and split datasets
- Generate Pivot Tables
- Create professional data visualizations
- Save graphs as image files

This project demonstrates practical usage of Python libraries for real-world business data analysis.

# 🚀 How to Run

1. Open Jupyter Notebook.
2. Install required libraries.

```
pip install pandas numpy matplotlib seaborn
```

3. Place `sales_data.csv` in the project folder.
4. Run all notebook cells.
5. Create an object:

```python
obj = SalesDataAnalyzer()
obj.menu()
```

6. Select menu options to perform operations.
